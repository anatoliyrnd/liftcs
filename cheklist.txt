 HANDOFF: Переход Lift-Calls на реальный Бэкенд (Мультитенантность)
Статус: Фронтенд полностью готов (API v4.0 интегрирован). Переходим к написанию реального бэкенда на PHP 8.3+ с использованием PDO.

🏗️ Утвержденная Архитектура (Multi-Tenant)
Master DB (Глобальная база):

Хранит адресное пространство: lift_city, lift_street, lift_home, lift_object (единые для всех).

Таблица lift_organizations: содержит org_key, название и реквизиты подключения (host, dbname, user, password) к базе конкретной организации.

Tenant DB (База организации):

Хранит пользователей (lift_users), заявки (lift_calls), историю и настройки.

Таблица lift_lkds_bindings: связка глобального object_id с локальным lkds_domain_id для интеграции со Spult.

Таблицы групп: lift_groups и lift_group_objects (связь с глобальными ID лифтов/домов/улиц).

Интеграция со Spult: Односторонняя. Spult присылает XML -> бэкенд парсит -> TicketService создает/объединяет заявку. Автосоздание адресов из XML запрещено (только логирование ошибок).

Часть 2: Код TicketService.php
Этот сервис использует PDODB и реализует ту самую логику бизнес-дублей, о которой мы договаривались.

php
<?php
declare(strict_types=1);

namespace mainSRC\services;

use mainSRC\dataBase\PDODB;
use Exception;

class TicketService
{
    private PDODB $db;

    public function __construct()
    {
        // Предполагается, что PDODB настроен на текущую Tenant DB
        $this->db = PDODB::getInstance();
    }

    /**
     * Создает новую заявку или объединяет с существующей.
     * 
     * @param array $data Нормализованные данные от SPA или Spult
     * @return int ID созданной или обновленной заявки (call_id)
     * @throws Exception
     */
    public function createOrMerge(array $data): int
    {
        // 1. Защита от повторной синхронизации офлайн-пачки (Идемпотентность)
        if (!empty($data['offline_uuid'])) {
            $alreadyExists = $this->db->single(
                "SELECT call_id FROM lift_calls WHERE offline_uuid = :uuid",
                ['uuid' => $data['offline_uuid']]
            );
            if ($alreadyExists) {
                return (int)$alreadyExists; // Молча возвращаем ID, заявка уже создана
            }
        }

        // 2. Поиск бизнес-дубля (Лифт + Тип неисправности + Отдел)
        // call_status = 0 означает, что заявка открыта
        $existing = $this->db->row(
            "SELECT call_id, call_details FROM lift_calls 
             WHERE call_status = 0 
               AND address_lift = :lift_id 
               AND call_request = :req_id 
               AND call_department = :dept_id 
             LIMIT 1",
            [
                'lift_id' => $data['object_id'],
                'req_id'  => $data['request_id'],
                'dept_id' => $data['department_id']
            ]
        );

        if ($existing) {
            // 3. Нашли дубль — дописываем текст в существующее описание
            $dateStr = date('d.m.Y H:i');
            $author = $data['author_name'] ?? 'Система';
            $source = $data['source'] ?? 'API'; // 'SPA', 'Offline', 'Spult'
            
            $newDetails = $existing['call_details'] 
                . "\n\n--- [Дубль от {$dateStr} | Источник: {$source} | Автор: {$author}]: \n" 
                . $data['details'];

            $this->db->update('lift_calls', 
                ['call_details' => $newDetails], 
                ['call_id' => $existing['call_id']]
            );

            return (int)$existing['call_id'];
        }

        // 4. Дубля нет — создаем новую заявку (Маппинг API -> Legacy DB)
        $insertData = [
            'offline_uuid'         => $data['offline_uuid'] ?? null,
            'call_status'          => 0, // 0 = открыта
            'call_date'            => time(),
            'call_first_name'      => $data['author_name'] ?? 'API',
            'call_department'      => $data['department_id'],
            'call_request'         => $data['request_id'],
            'call_group'           => $data['group_id'],
            'call_adres'           => $data['fullAddress'],
            'call_details'         => $data['details'],
            'call_solution'        => '',
            'call_user'            => $data['user_id'] ?? 0,
            'call_staff'           => $data['staff_id'] ?? 0,
            'address_city'         => $data['city_id'],
            'address_street'       => $data['street_id'],
            'address_home'         => $data['home_id'],
            'address_lift'         => $data['object_id'],
            'expected_repair_time' => $data['repair_time']
        ];

        return (int)$this->db->insert('lift_calls', $insertData);
    }

    /**
     * Добавление комментария (заметки) к заявке.
     */
    public function addNote(int $callId, string $noteText, int $userId, string $userName): bool
    {
        $this->db->beginTransaction();
        try {
            // 1. Вставляем заметку в таблицу lift_notes
            $this->db->insert('lift_notes', [
                'note_title'     => 'Комментарий',
                'note_body'      => $noteText,
                'note_relation'  => $callId,
                'note_type'      => 1, // Тип: обычный комментарий
                'note_post_date' => time(),
                'note_post_user' => $userId
            ]);

            // 2. Пишем в историю заявки
            $historyText = "{$userName} добавил(а) комментарий: " . mb_substr($noteText, 0, 100) . "...";
            $this->db->insert('lift_history', [
                'history_date' => time(),
                'history_info' => $historyText,
                'call_id'      => $callId
            ]);

            $this->db->commit();
            return true;
        } catch (Exception $e) {
            $this->db->rollBack();
            throw $e;
        }
    }
}
💡 Как это работает в контексте архитектуры:
В api.php (или test_calls.php) при получении запроса callnew ты просто создаешь экземпляр new TicketService() и вызываешь createOrMerge($input).

Если это пачка офлайн-заявок (callNewOffline), ты оборачиваешь вызовы createOrMerge в цикл внутри $db->beginTransaction() и $db->commit(). Если хотя бы одна упадет с ошибкой — rollBack() отменит всю пачку.

Для Spult в xml.php ты тоже вызываешь createOrMerge(), но передаешь source = 'Spult'. Если Spult пришлет ту же аварию, что уже висит в SPA, сервис просто допишет данные диагностики в описание, а не создаст вторую заявку.
